How it works

One stylesheet, redesign/tokens/luxury-mobile.css, overrides only the DS color variables under a .lux root. Add .dark for dark mode and data-palette to switch palettes. Every existing Radius component picks the new colors up automatically; CRM and web surfaces never load it.
